# Scope offscreen marker indicator

The channel marker is the authoritative zero/reference indicator for the channel Y scale. When that reference is outside the visible eight-division plot, its pinned top/bottom marker and directional point indicate which way the channel reference — and therefore the offset trace frame — lies offscreen. This indicator is based on the selected channel scale and offset, not on transient waveform sample extrema.
